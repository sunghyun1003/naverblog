## 이번 적용

1. **편집 전용 응답 계약**: 본문 필드와 GEO 직접 답변만 받는다. 정식 원고 스키마에서 필요한 부분을 추출하므로 본문 구조, 정확히 3개의 핵심 요약, 3~5개 FAQ 기준은 같다.
2. **원본 결합**: 출처 URL·sourceType·evidenceIds·factChecks·기획·SEO·GEO 보조 정보·이미지 계획·추가 메타데이터는 원본 그대로 결합한다. 이전의 전체 JSON 응답도 계속 지원한다.
3. **누락 응답 보호**: 본문 필수 필드가 빠진 응답은 원본을 덮어쓰지 않는다. 일반 편집 실패 시 이전 원고로 최종 검수하고, 최종 보정 응답이 불완전하면 이전 원고와 차단 판정을 보존한다. 실패를 성공으로 위장하지 않는다.
4. **초안 입력 정리**: 이미 사용이 끝난 후보 선정 점수·순위만 프롬프트에서 제외했다. 후보 자체, 본문 참고 요약, 원본 스냅샷·선정 기록은 삭제하지 않는다.
5. **조사 종료 지침**: 필요한 핵심 질문에 집중하고 공식 페이지를 재사용한다. 최소 3개 공식 출처·2개 기관 및 핵심 주장의 근거·조건을 확보하면 결과를 반환한다. 근거가 없으면 미해결로 남기며 검증 기준은 낮추지 않는다. 이는 모델의 작업 지침이며, 검색 횟수나 토큰을 강제로 차단하는 제한은 아니다.

기존 최종 검수, HIGH 차단, 보정 횟수 상한, API 인증, 사용 모델, 자동 일정, 이미지 생성 로직은 바꾸지 않았다. 과금 발생 테스트나 기존 원고 재생성도 실행하지 않았다.
