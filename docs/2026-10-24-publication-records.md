# 수동 발행 기록 고도화

## 적용 범위

- 발행 관리의 발행 완료 원고에서 `게시 URL · 수정 메모`를 열어 URL을 보완/정정하고 게시 후 수정 메모를 누적한다.
- PC 및 모바일 네이버 HTTPS URL을 지원하며, URL 없이 발행 완료 처리하는 기존 동작도 유지한다.
- 기록은 작성 시각(한국 시간), 메모, 해당 시점의 URL을 보존한다. URL을 지워도 과거 이력은 남는다.
- 이 메모는 실제 네이버 게시본에 관한 운영 기록이다. 준법심의 학습 규칙은 기존 `준법심의 피드백`에서 별도로 관리한다.

## 기존 기능 보호

- 원고 본문/이미지/품질 상태/기존 발행 시각/원고 버전은 변경하지 않는다. Word·복사·네이버 임시저장 패키지에도 영향을 주지 않는다.
- 자동 발행, 원고 재생성, AI 호출, 새 검수 조건을 추가하지 않았다.
- 운영 데이터는 비공개 자동화 저장소의 `dashboard/publication-records/<contentId>.json`에만 저장한다. 기존 결정 파일의 URL은 최초 발행 당시 기록으로 보존하며, 새 패널에서는 별도 기록의 최신 URL을 표시한다.
- 기록이 없는 기존 원고는 최초 발행 URL을 읽기만 한다. 마이그레이션/일괄 수정 없이 처음 저장하는 때에만 파일을 만든다.
- 로컬 mock 모드만 메모리 저장소를 사용한다. 실제 운영은 기존 GitHub 서버 권한을 그대로 사용하며 새 서비스/DB 변경은 없다.

## 안정성과 조회 비용

- 목록을 열 때 기록 조회 요청은 0회. 사용자가 패널을 열 때만 작은 결정 파일과 발행 기록 파일을 병렬 조회한다. 원고 전체나 이미지 파일은 읽지 않는다.
- 저장도 별도 요청으로 수행하여 원고 목록/상세 캐시를 무효화하지 않는다.
- revision과 GitHub SHA 비교로 동시 수정 덮어쓰기를 방지한다. 동일 요청 ID 재시도는 메모를 중복 추가하지 않는다.
- 저장 실패/충돌 시 입력을 남긴다. 기록 새로고침 시 작성 중인 메모와 사용자가 직접 바꾼 URL을 보존한다.
- 손상된 파일, 미발행/삭제 원고, 권한 없는 쓰기는 거절한다. 외부 사이트/비HTTPS/인증정보 포함 URL도 거절한다.
- 원고당 최대 100건, 메모 2,000자, URL 2,048자로 제한하여 한글 최대 길이에서도 GitHub 인라인 조회 크기 안에 유지한다. 한도 도달 시 기존 기록을 삭제하지 않는다.

## 검증

- `npm run verify`: 타입 검사, 183개 테스트, 프런트/서버 빌드.
- `npm run writer:test`: 원문·이미지·AI 주석·필수 안내 이미지·심의필 보존 6개 테스트.
- Browser plugin not available → 기존 Playwright/Chrome headless 사용. 별도 설치 없음.
- 로컬 실제 API/mock 데이터: `/schedule` 진입 → 패널 열기 → 저장 → 재조회. 최초 조회 0회, 저장 응답 유실 후 재시도 1건만 저장, 동시 수정 충돌 후 입력 보존/재저장 확인.
- 저장 전후 원고 상세 전체 비교 일치. 운영 원고와 실제 네이버 게시글에는 테스트 기록을 남기지 않았다.
- 1440×1000, 390×844, 320×844 화면 확인. 페이지 식별/본문 렌더링/오류 오버레이 없음/동작 확인. 개발 서버 기본 favicon.ico 404만 확인했으며 앱 런타임 오류는 없었다.
- 화면 검사 중 메모 입력란의 접근성 이름을 고정하고, 기존 상단바가 320px에서 10px 넘치던 문제는 해당 폭에서만 계정 영역 좌우 여백을 줄여 수정했다. PC 공통 시작 위치/좌측 정렬은 유지한다.
- 테스트 스크립트와 스크린샷은 시스템 임시 폴더에만 저장한다.

## 남은 순서

1. 10/23 섹션 집중 편집 정책 이후 실제 신규 원고가 생성되면 문체/체크리스트 반복과 이미지 구도를 재평가한다. 기존 원고는 수정하지 않는다.
2. 연구 단계 비용은 관측 자료가 더 쌓인 뒤 필요한 검색 축소만 적용한다. 관측이 부분적인 현재 값만으로 임의 제한하지 않는다.
3. 별도 정시 실행 서비스는 권한·비용에 관한 사용자 결정 후 진행한다. 이번에는 스케줄을 변경하지 않았다.
