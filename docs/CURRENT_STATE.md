# 현재 운영 기준과 남은 개선

기준일: 2026-10-30. 초기 설계와 이후 사용자 결정이 다른 경우 **최신 사용자 요구와 현재 코드·회귀 테스트**를 따른다. 이 문서는 과거 기능을 복원하기 위한 신규 구현 목록이 아니다.

## 변경하지 않을 운영 원칙

- 본문·이미지의 필수 검사를 통과하면 자동 완성한다. 없앤 사람 검토 체크리스트·승인 대기 단계를 다시 필수로 만들지 않는다. 문체 선호와 비차단 권고를 새 실패 조건으로 만들지 않는다.
- 네이버 최종 발행은 사용자가 한다. PC 도우미는 PC가 켜져 있고 연결된 경우의 **임시저장 보조**다. 현재 대상은 `hanwhains_carrot`, 카테고리는 `자동차보험`이다. 이전 계정으로 되돌리지 않는다.
- 발행 예정은 운영 기록이며 자동 발행/알림 기능이 아니다. 예정 해제·변경과 수동 발행 완료 기록, 게시 URL·수정 메모를 유지한다.
- 기존 원고·이미지·준법심의 의견·심의필·수동 수정본은 요청 없이 일괄 재작성하지 않는다. 편집 고도화는 신규 등록 정책으로 적용하고 재시도는 해당 원고의 저장 정책을 따른다.
- PC 화면의 제한 너비·좌측 정렬·탭별 공통 시작 위치를 유지한다. 불필요한 탭명 제목과 중복 입력 테두리를 복원하지 않는다.
- 콘텐츠 번호는 표시 순서와 분리해 유지한다. 위아래 이동이나 검색으로 다시 계산하지 않는다. 전체 번호 초기화는 별도의 명시적 요청 때만 수행한다.
- 3줄 요약·FAQ·공식 근거·필수 조건을 유지한다. 사명은 ‘한화손보’, 자사 자동차보험 상품명은 ‘한화손보 캐롯 자동차보험’이다.
- AI 이미지의 노출 주석은 ‘AI로 생성한 이미지입니다.’이며 대체 설명은 유지한다. 공통 하단 안내 이미지·심의필은 본문·Word·복사·임시저장 패키지에도 보존한다.

## 현재 연결

- 화면: Firebase Hosting. 로그인·작업 API: Cloud Run. 화면 조회 사본: Neon. 원고·이미지·실행 원본과 자동화: 비공개 GitHub 저장소.
- 일반 탭 조회를 원격 원고 전체 재수집으로 되돌리지 않는다. [조회 경로](./DASHBOARD_READ_MODEL.md)를 따른다.
- 생성은 기존 OpenAI API 키를 사용한다. 키를 문서나 로그에 적지 않는다. OAuth 관련 호환 코드가 있다고 현재 실행을 OAuth 전용으로 설명하지 않는다.
- 정기 수집·생성의 기준은 비공개 자동화 저장소 `config/automation-settings.json`과 연결된 workflow다. 오래된 문서의 시간·호출 예산을 하드코딩하지 않는다.
- 대시보드 코드 main push는 검증 후 자동 배포한다. 비공개 자동화 코드 변경은 다음 실행부터 적용되며 화면 코드가 바뀌지 않았다면 화면 재배포는 필요 없다.

## 남은 개선과 경계

| 항목 | 현재 단계 | 다음 확인/결정 |
| --- | --- | --- |
| 신규 원고의 자연스러움·이미지 다양성 | 설명 단위 샘플, 본문 반복 안내, 주제별 장면 정책 반영 | 신규 3~5건의 실제 문장·이미지 비교. 점수만으로 완료 선언하지 않음 |
| 사용량과 재수정 감소 | 조사·작성·편집·최종 검수 입력 정리 및 단계별 계측 반영 | 실제 토큰·캐시·보정 횟수 비교. 입력 bytes 감소를 비용 감소로 환산하지 않음 |
| 준법심의 피드백 | 입력·누적·보종별 선택·최초 적용 기록 고정 구현 | 실제 피드백을 받은 신규 원고에서 반영 확인. 기존 원고 소급 적용 금지 |
| 독립적인 정시 트리거 | 미도입 | 운영 권한·무료 범위/비용에 대한 사용자 결정 후 진행. 임의 서비스/IAM 추가 금지 |
| 수동 발행 기록 | URL·발행 후 수정 메모 구현 | 실제 발행본과 생성 원고를 구분. 조회수나 검색 성과 추정 금지 |
