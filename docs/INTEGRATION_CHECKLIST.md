# 내일 결정할 연동 체크리스트

아래 값만 정하면 현재 모의 어댑터를 실제 제공자로 교체할 수 있다.

## 1. 회사 로그인

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| 회사 Google/Microsoft SSO | 팀원 입퇴사 관리가 쉽다 | 회사 계정 관리자 설정 필요 |
| 관리형 인증 서비스 | 개발과 유지보수가 빠르다 | 사용자 수에 따라 비용 발생 |
| 자체 계정 | 통제 범위가 넓다 | 보안·복구·MFA 유지보수 부담이 크다 |

권장: 이미 사용하는 회사 계정 SSO. 필요한 값은 회사 도메인, 로그인 제공자, 관리자·승인자 명단이다.

## 2. PostgreSQL 운영 방식

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| 관리형 PostgreSQL | 백업·장애 대응이 쉽다 | 월 비용과 제공자 종속 |
| 사내 PostgreSQL | 데이터 통제 | 운영 인력과 백업 체계 필요 |

필요한 결정: 개발·운영 분리, 국내 리전 요구, 보존 기간, 백업 복구 목표.

## 3. AI 생성 제공자

필요한 값: 제공자, 모델, 월 예산, 요청당 최대 비용, 데이터 보관 허용 여부, 장애 시 대체 모델.

권장 운영 원칙:

- 제공자 SDK를 도메인 코드에서 직접 호출하지 않는다.
- 단계별 모델·비용·입출력 버전을 기록한다.
- 금융 수치·인용·상품명은 보호 문구로 전달한다.
- 모델 실패는 작업 실패로만 기록하고 이전 버전을 보존한다.

## 4. 트렌드 수집

필요한 값:

- 네이버 검색 API 애플리케이션
- YouTube Data API 프로젝트
- 허용할 커뮤니티·RSS·URL 목록
- 수집 주기와 일일 한도
- 원문 저장 범위와 삭제 기간

원칙: 인기 자료는 질문·관점·목차 힌트로만 사용하고, 금융 사실은 공식 자료에서 다시 검증한다.

## 5. 사람 말투 skill

필요한 값:

- skill 위치 또는 호출 방식
- 입력·출력 형식
- 버전 이름
- 보호할 문구 규칙
- 변경 diff 제공 여부
- 실패·타임아웃 기준

연결 계약은 [사람 말투 Skill 계약](./HUMAN_TONE_SKILL_CONTRACT.md)에 정의돼 있다.

## 6. Slack

필요한 값: 워크스페이스, 알림 채널, 앱 권한 승인자, 담당자 멘션 규칙.

Slack은 생성 요청과 알림만 담당한다. 최종 승인은 출처와 원고를 함께 보는 웹 관제 페이지에서 한다.

## 7. 네이버 발행

| 선택지 | 장점 | 단점 |
| --- | --- | --- |
| 사람이 최종 붙여넣기·예약 | 가장 안정적이고 계정 위험이 낮다 | 수동 작업이 남는다 |
| 로그인 브라우저 입력 보조 | 반복 입력 감소 | UI 변경·세션 만료 대응 필요 |
| 완전 자동 발행 | 운영 속도 | 계정·정책·오발행 위험이 가장 크다 |

권장 시작점: 승인된 콘텐츠만 브라우저 입력 보조로 준비하고, 발행 버튼은 사람이 누른다.

## 8. 회사 정책

결정이 필요한 항목:

- 정보형·광고형 콘텐츠 분류
- 최종 승인 책임자
- 필수 고지 문구
- 금지 표현과 비교 표현
- 출처 신뢰 등급
- 수정·삭제·정정 절차
- 감사 로그와 원문 보존 기간
- 업무 시간 외 자동화 실패 알림 방식
