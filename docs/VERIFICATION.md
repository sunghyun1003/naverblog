# 프론트엔드 1차 검증 기록

## 자동 검사

- `npm run check`: 통과
- `npm run build`: 통과
- 브라우저 콘솔 경고·오류: 0건

## 브라우저 기능 검사

- 콘텐츠 생성 모달: 주제 입력 후 새 기획 행과 완료 알림 생성
- 제목 검색: 입력한 제목에 맞는 행만 표시
- 상태 필터: `검토 필요` 선택 상태와 대상 행 표시
- 검수 화면 이동: 목록 행에서 원고·근거·변경 이력 화면으로 이동
- 승인 조건: 출처와 광고 표현 확인 전에는 승인 불가
- 승인 완료: 두 항목 확인 후 상태가 `예약`으로 변경
- 1280px 화면: 문서 전체 가로 넘침 없음

## 시안 비교

1. 좌측 탐색, 중앙 작업 영역, 우측 보조 패널의 3단 구조를 유지했다.
2. 주황색은 주요 실행 버튼과 선택 상태에만 사용했다.
3. 카드 그림자 대신 보조 배경과 1px 구분선으로 계층을 표현했다.
4. 대시보드는 상태 요약, 필터, 목록, 오늘 할 일 순서를 유지했다.
5. 검수 화면은 문서 목차, 원고, 검수 결과와 출처를 한 화면에서 비교하도록 유지했다.

대시보드 상단 문구는 시안과 동일하다. 검수 원고의 단정적인 보험 표현은 실제 발행 오인을 막기 위해 약관 확인과 개인별 유불리 안내 문구로 바꿨다. 검토 콘셉트에 생성된 당근형 심볼은 브랜드 오인 방지를 위해 중립적인 자체 문서 마크로 교체했다.

## 남은 시각 검사

현재 내장 브라우저는 390×844 및 1536×1024 요청에도 실제 렌더링 크기를 1280×720으로 고정했다. 1280×720 실제 화면과 1536×1024 시안 원본은 각각 확인했지만, 모바일 실기기 시각 검사는 다음 단계에서 Chrome DevTools 또는 실제 기기로 수행해야 한다. 767px 이하 레이아웃 규칙과 모바일 메뉴 DOM은 코드 수준에서 포함돼 있다.
