# 블로그 운영센터 디자인 규격

## 기준 콘셉트

- 대시보드: `docs/design/dashboard-concept.png`
- 원고 검토: `docs/design/review-concept.png`

두 이미지는 구현을 위한 시각 기준이며 실제 UI 텍스트와 컨트롤은 모두 코드로 작성한다.

## 디자인 방향

SEED Design의 시각 원칙을 참고하되 당근의 브랜드 자산과 제품 개념은 사용하지 않는다.

- 역할 기반 색상
- 시스템 폰트
- 2px 단위 간격과 4px 기반 스케일
- 둥글고 부드러운 형태
- 굵고 간결한 선형 아이콘
- 표면색과 1px 선을 우선하는 계층
- 그림자는 떠 있는 소수 요소에만 사용
- 주황색은 주요 CTA와 선택 상태에만 사용

## 레이아웃

- 데스크톱 사이드바: 248px
- 검토 화면 보조 목차: 190px 내외
- 대시보드 우측 작업 레일: 320px 내외
- 대시보드 컬럼 간격: 24px
- 데스크톱 화면 여백: 32px
- 768px 미만: 사이드바를 헤더 메뉴로 전환
- 모바일: 테이블을 정보 행 목록으로 전환

## 허용된 주요 화면 문구

### 대시보드

- 블로그 운영센터
- 콘텐츠 운영
- 기획부터 발행까지 한곳에서 관리하세요.
- 콘텐츠 만들기
- 홈, 트렌드 수집, 콘텐츠, 발행 일정, 성과, 설정
- 전체, 기획, 작성 중, 검토 필요, 예약, 발행 완료
- 오늘 할 일, 최근 활동

### 검토 화면

- 실손보험 세대별 차이, 무엇이 달라졌을까?
- 원고, 근거, 변경 이력
- 검수 결과, 말투 보정 변경, 출처, 최종 확인
- 반려, 승인하기

## 의도적 차이

- 검토 콘셉트의 당근형 심볼은 구현하지 않는다. 대시보드 콘셉트의 중립적인 자체 문서 마크로 통일한다.
- 샘플 보험 수치는 실제 상품 정보가 아니므로 구현에서는 구조 설명용 문구로 제한하고 외부 발행 데이터로 사용하지 않는다.
- 당근, SEED Design, 패키지명은 제품 UI에 노출하지 않는다.
