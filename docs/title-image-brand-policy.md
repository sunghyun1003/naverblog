# 제목 다양성·AI 이미지 표시·상단 브랜드 영역

2026-10-06. 제목/이미지 변경은 적용, 브랜드 영역은 제안 단계입니다.

## 적용 범위

- 새 원고 생성은 최근 8개 제목을 참고해 상황형·질문형·설명형·확인/방법형 중 덜 반복된 표현을 우선 고려합니다. 기존 주제 순환, 고정 주제와 검색의도는 변경하지 않습니다. 수동 지정 주제도 같은 지침을 사용합니다.
- 기존 3~5개 제목 후보를 서로 다른 시작 문구와 구조로 작성하도록 합니다. 보종·세부 키워드를 유지하지만 맨 앞 고정, 정확히 붙여쓰기, 같은 종결 표현을 강요하지 않습니다. 말투 보정도 이를 보존합니다.
- 표현 다양성은 새로운 실패/재호출 조건이 아닙니다. 기존 원고 제목을 일괄 변경하거나 추가 AI 검수 호출을 하지 않습니다. 15~55자는 내부 편집 목표이지 검색엔진의 공식 글자 수 제한이 아닙니다.
- AI 이미지에는 ‘AI로 생성한 이미지입니다.’를 화면 본문, 이미지 탭, 이미지 포함 복사, HTML 소스 복사, 새 HTML 패키지, Windows 도우미 미리보기/실제 입력에 표시합니다. alt는 장면 설명으로 유지합니다.
- 기존 이미지도 대시보드에서 다시 열거나 복사하면 주석을 붙입니다. 이미 외부 블로그에 저장·발행한 글이나 내려받은 과거 HTML은 소급 변경하지 않습니다. Windows 도우미는 실행 중 작업을 보존한 뒤 재시작해야 새 코드를 사용합니다.

## 브랜드 영역 제안 — 승인 전 자동 삽입 안 함

권장 순서: 제목 → 짧은 도입·직접 답변 → 한화손보 캐롯 핵심 포인트 → 기존 3줄 요약 → 본문·FAQ.

작은 텍스트 박스 한 개에 아래 내용을 넣습니다. 이미지에만 문구를 넣거나 숨김 텍스트로 반복하지 않습니다.

1. 공통 소개 한 문장: 회사가 승인한 브랜드명·운영사 관계를 명확히 설명.
2. 현재 글과 관련된 승인 USP 1~2개: 브랜드명을 주어로 쓰고 상품명·적용 조건까지 같은 문장/항목에서 설명.
3. 공식 상품안내 링크와 확인일. 할인 수치나 특약은 기준일/조건을 가까이 표시.

주행거리 글에는 주행거리 정산 방식, 가입 절차 글에는 온라인 가입 편의 등 관련성이 있는 USP를 고릅니다. 자동차보험 USP를 여행보험·암보험 등 다른 상품의 장점처럼 붙이지 않습니다. 관련 USP가 없거나 만료됐으면 짧은 공통 소개만 남기고, 브랜드 문구 때문에 원고 전체를 실패시키지 않는 구성을 권합니다.

구현 시 별도 승인 문구 목록(상품·관련 주제·문구·조건·공식 URL·유효기간)을 사용하고 AI가 USP나 수치를 새로 만들게 하지 않습니다. 초기 등록할 회사 승인 소개 문장과 USP 목록은 사용자 확인이 필요합니다.

상단 배치는 AI가 읽을 수 있는 브랜드 맥락을 제공하기 위한 편집 제안입니다. 특정 부분의 인용이나 USP 동반 인용을 보장하지 않습니다. 독자 질문의 답을 밀어내는 긴 광고 문구는 피합니다.

## 검증 경계

유료 생성 호출이나 네이버 실제 글 저장 없이 생성 프롬프트 통합 검사, 기존 주제·복구·검수 회귀 검사, 실제 저장 원고를 사용한 PC/모바일 렌더링 및 복사 HTML 검사로 확인합니다. 실제 생성 제목의 표현 품질과 네이버 저장 결과는 이 검사만으로 입증한 것으로 표시하지 않습니다.
