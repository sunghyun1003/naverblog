# 원고 Word 다운로드

콘텐츠 목록에서 원고를 열고 상단의 **Word 다운로드**를 누릅니다. 저장된 제목을 파일명으로 하는 `.docx` 파일이 내려받아집니다.

- 최신 저장 버전의 제목과 본문 전체를 사용합니다. 직접 수정한 내용도 포함합니다. 다운로드 과정에서 AI 재작성이나 문구 변경은 하지 않습니다.
- 소제목, 굵은 글씨, 목록, 비교표, 링크, 본문에 있는 요약·FAQ·안내문을 편집 가능한 Word 요소로 만듭니다.
- 본문에 적용된 이미지만 내장합니다. 사용자가 반려 이유를 확인하고 적용한 이미지도 포함하며, 각 이미지의 설명과 AI 생성 주석을 유지합니다. 이미지 링크의 만료나 로그인이 파일 열기에 영향을 주지 않습니다.
- 이미지 없는 저장 원고도 다운로드할 수 있고, 이 경우 화면에 글만 포함됐다는 안내를 표시합니다. 본문에서 제외한 이미지는 포함하지 않습니다.
- 선택한 이미지의 다운로드·무결성 확인에 실패하면 부분 파일을 만들지 않습니다. 원고가 바뀌면 새로고침을 요청하며, 생성·재작성 중에는 다운로드를 막습니다.
- 화면 데이터의 확인 시각이 오래됐다는 이유만으로 다운로드 버튼을 잠그지 않습니다. 클릭 시 서버에서 원본과 버전을 확인합니다. 실제로 원고가 바뀐 경우에는 최신 내용을 화면에 불러오고, 확인 후 다시 내려받도록 안내합니다.
- 로그인한 대시보드 사용자만 내려받을 수 있습니다. 승인·발행 상태나 원본 원고를 바꾸지 않습니다. 다운로드 자체가 준법심의 완료를 의미하지는 않습니다.

## 구현과 검증

`GET /api/contents/:id/word?versionId=...&updatedAt=...`는 최신 원고 버전을 확인한 뒤 DOCX를 생성합니다. `Cache-Control: private, no-store`를 사용하고 이미지 바이너리의 SHA-256을 원고 메타데이터와 대조합니다. 외부 URL을 임의로 가져오지 않습니다.

문서 라이브러리는 이 요청에서만 지연 로딩합니다. 일반 페이지 진입이나 글 생성 파이프라인에서 실행되지 않으며 AI 토큰을 사용하지 않습니다.

`tests/word-export.test.ts`는 ZIP 무결성, 한글·긴 본문·표·목록·링크 보존, 이미지 내장과 주석, 선택한 반려 이미지, 빈 원고·변경된 버전·이미지 오류 차단, 로그인·파일 응답을 검사합니다. 글 생성·복사·네이버 임시저장 회귀 검사는 기존 테스트를 유지합니다.

문서는 Letter 용지, 1인치 여백, 한글 맑은 고딕 계열, 11pt 본문으로 구성합니다. 글꼴이 없는 기기에서는 해당 Word 프로그램의 대체 글꼴이 적용될 수 있습니다. 2026-10-08 로컬 QA에서 실제 원고 전체·이미지 3장과 PC/모바일 다운로드를 확인했습니다. 해당 Windows 검증 환경에 지원되는 문서 페이지 렌더러가 없어 실제 Word 인쇄 레이아웃의 시각 검증은 별도로 필요합니다.
